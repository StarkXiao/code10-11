# 隧道衬砌巡检系统

汇聚**巡检影像**与**测缝计数据**，自动识别**裂缝扩展趋势**，对**超限段落**派发现场复核任务并跟踪闭环。

零外部依赖（Node ≥ 20 原生实现），开箱即用。

```bash
npm start          # http://localhost:8080（首次启动自动写入演示数据）
npm test           # 闭环集成测试（独立临时库，不碰演示数据）
npm run seed       # 强制重建演示数据
```

---

## 业务闭环

```
巡检影像上传（桩号定位 + 裂缝走向标注）
        +
测缝计读数上报（单条 / 网关批量 / 演示模拟）
        ↓
趋势引擎：读数按天聚合 → 近 30 天最小二乘回归 → 速率 / 加速度
        ↓
超限判定（阈值可配置）：
  · 缝宽 ≥ 0.5mm            → 超限
  · 速率 ≥ 0.01mm/d         → 超限
  · 缝宽 ≥ 0.3mm 或速率 ≥ 0.005mm/d 或加速扩展 → 预警
        ↓
告警（同缝未闭环只更新不新建，不轰炸）
        ↓
派发现场复核任务（超限自动派发 / 人工派发，含期限与说明）
        ↓
接单 → 现场复核 → 提交实测缝宽与结论
        ├─ 误报     → 告警闭环，静默 7 天
        ├─ 稳定     → 告警闭环，继续监测
        └─ 确认扩展 → 告警闭环，裂缝转「处置中」
```

**没有断头路**：告警只有「复核中 / 已闭环」两个去向；任务不完成，告警不闭环；误报有冷却期防止反复打扰。

## 页面

| 页面 | 说明 |
| --- | --- |
| 总览 | 统计卡、段落健康条带（40 段 × 100m 按级别着色）、扩展速率 TOP5、最新告警 |
| 裂缝台账 | 级别 / 趋势 / 段落筛选，速率与加速度排序定位风险裂缝 |
| 裂缝详情 | 缝宽时序图（阈值线 + 回归线 + 悬浮读数）、指标卡、关联影像、告警与任务史、手动补录读数 |
| 巡检影像 | 巡检记录、影像上传（自动压缩）、画布标注裂缝走向（归一化坐标）、关联裂缝 |
| 告警中心 | 超限规则配置（保存即全量重算）、告警列表、一键派发 |
| 复核任务 | 三列看板（待复核 / 复核中 / 已完成），逾期标红，结论回填闭环 |
| 测缝计 | 设备台账、最近读数、网关批量上报示例 |

顶栏「⏩ 模拟次日读数」可为全部测缝计推进一天数据，用于演示趋势实时演化。

## API 摘要

```
GET  /api/overview                     总览统计 + 段落健康
GET  /api/cracks?level=&trend=         裂缝列表（含趋势缓存）
GET  /api/cracks/:id                   详情：时序 / 影像 / 告警 / 任务
POST /api/cracks                       登记裂缝
POST /api/inspections                  新建巡检
POST /api/inspections/:id/images       上传影像（dataURL + 标注）
POST /api/gauges/:id/readings          单条读数上报（同日幂等覆盖）
POST /api/readings/batch               网关批量上报（部分失败独立返回）
POST /api/simulate/day                 演示：全部设备推进一天
GET  /api/alarms?status=               告警列表
POST /api/alarms/:id/dispatch          派发复核任务（重复派发 409）
GET  /api/tasks?status=                任务列表
POST /api/tasks/:id/claim              接单
POST /api/tasks/:id/complete           提交复核结果 → 告警闭环
PUT  /api/config/thresholds            调整阈值并全量重算
POST /api/analysis/run                 手动全量重算
```

### 测缝计网关对接示例

```bash
curl -X POST http://localhost:8080/api/readings/batch \
  -H 'Content-Type: application/json' \
  -d '{"readings":[{"gaugeCode":"CG-001","widthMm":0.523,"temperature":18.5}]}'
```

## 趋势算法

- 读数按**天聚合**（日均值），消除一日多次上报噪声；
- 近 N 天（默认 30）**最小二乘回归**，斜率即扩展速率 mm/d，附带 R² 拟合度；
- 前一窗口（30~60 天前）回归对比得**加速度**，识别「越裂越快」；
- 分级：`稳定 / 缓慢扩展 / 加速扩展 / 数据不足`；
- 超限三要素：当前缝宽、扩展速率、加速趋势，阈值均可在告警中心在线调整。

## 演示数据

青云山隧道（K10+000~K14+000，40 段）：12 条裂缝覆盖稳定 / 缓慢 / 加速 / 阶跃四种形态，90 天逐日读数（含温度效应与量测噪声，确定性伪随机生成，任意机器结果一致），3 次巡检 6 张影像，1 条复核中任务 + 1 条已闭环任务。

## 目录

```
server/
  index.js     服务入口（启动时自动 seed + 全量评估）
  api.js       REST 路由 + 静态托管
  analysis.js  趋势引擎：回归 / 分级 / 超限判定 / 告警去重 / 自动派发
  seed.js      演示数据（确定性）
  store.js     JSON 原子写存储
public/        原生前端（无构建步骤）
test/          闭环集成测试（node:test）
```

数据文件：`server/data/db.json`（可用 `DATA_FILE` 环境变量指定）；端口用 `PORT` 指定。
